## §12 Implementation audit — why grouping was not visible before
- **Render owner** = `render(view)` in `automation-schedule.js` — it did `host.innerHTML = jobs.map(renderJobCard).join('')`, a **flat** concatenation of cards into `#auto-sched-cards`. **Card renderer** = `renderJobCard(job)`. **Data source** = the server view `automationSchedule.get` → `automationBuildView_` (45_) `jobs[]` (registry keys). The prior F1-6B rounds split the **registry + handlers** only; **no round ever changed the render DOM**, so the page stayed a flat list. **Old misleading top flow** = the static `.auto-sched-flow` markup ("Source Import → Inventory Gap → Recommendation") in the HTML partial — a single-branch representation that became wrong after the Weekly/Monthly split.

## What changed
- **JS** — a presentation-only `AUTOMATION_GROUPS` map (source/inventory/order → the EXISTING registry keys, in the required order) + a new `renderGroupsHtml(jobs)` that emits three `<section class="automation-group automation-group--{key}">` containers, each with a title, a 1-line helper, and a real `.automation-group__cards` container holding that group's cards. `render()` now calls `renderGroupsHtml(jobs)`. A card whose key is not mapped falls into an "Other" group (never dropped); empty groups are omitted. The per-card seeding + Save & Apply still locate cards via `host.querySelector('.auto-card[data-key=…]')` (nesting-safe — unchanged).
- **HTML** — removed the misleading `.auto-sched-flow` block (§8; the grouped sections now convey the truthful Source → Inventory / Order relationship).
- **CSS** — removed the dead `.auto-sched-flow*` rules; `#auto-sched-cards` gap → 22px (between groups); added restrained `.automation-group__title` (uppercase 13px, stronger than the 11px card labels, weaker than the 20px page title), `.automation-group__desc`, and `.automation-group__cards` (subtle 2px left rule + 12px indent). A `max-width:640px` breakpoint drops the left rule/indent so narrow screens use full card width (no horizontal overflow); the card field grid stays `auto-fit minmax(150px,1fr)`.
