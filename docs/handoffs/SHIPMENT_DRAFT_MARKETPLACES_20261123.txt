SHIPMENT DRAFT - CONSOLIDATED MARKETPLACE LABELS
Date: 2026-11-23 (Asia/Taipei)

The Draft card's Marketplace field now lists the nonblank sourceMarketplace
values on its active shipment lines, in source order. Values are trimmed and
deduplicated case-insensitively, preserving the first spelling. Removed lines and
explicit lines of another shipment cannot contribute labels. With no usable
line provenance, the original shipment marketplace/-- fallback remains.

The label is HTML-escaped by the existing card renderer. It does not rewrite
the shipment marketplace, derive source identities from SKU grouping or change
any quantities, warehouse eligibility, filters, dispatch, documents or inventory.
Overview retains its existing header label. No new network request is added.
