Import Factory Inventory Snapshot

Mode: Set Current Stock — the imported current_stock_qty becomes the factory current stock for warehouse_id + sku (it does not add). Supplier is not required. Reserved / in-production / pending shipout / orders / shipments are not changed.
Columns: warehouse_id, warehouse_code, sku, current_stock_qty, effective_date, note. warehouse_id and sku must match canonical values. First row must be the header row.
