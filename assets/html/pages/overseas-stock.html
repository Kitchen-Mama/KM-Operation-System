Import Overseas Inventory Snapshot

This import updates ONE overseas warehouse only. Select the scope, then download the scoped template — warehouse_id is prefilled. Do not mix warehouses in one file.
Company / country / warehouse name are resolved from warehouse_id (do not type them). Quantities must be numbers ≥ 0 (decimals round up). Non-numeric values are rejected.

Inventory Adjustment

Select a snapshot record, then set the new Available quantity. Only available_stock is adjusted — reserved / physical / damaged / on-the-way are never changed. The snapshot row must already exist (import it first).
